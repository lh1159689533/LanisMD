# 架构决策记录 (ADR)

本目录记录项目中**不可逆的架构决策**，用于沉淀"为什么这样设计"，避免后续反复摇摆。

## 命名规范

- 文件名：`NNNN-<kebab-case>.md`，编号从 `0001` 递增
- 例如：`0001-use-milkdown-as-editor.md`

## 记录内容

每份 ADR 至少包含：

1. **背景**：为什么需要做这个决策
2. **决策**：最终选择了什么
3. **备选方案**：考虑过哪些替代方案，为何放弃
4. **影响范围**：该决策影响哪些模块/接口

## 与术语表的分工

- **术语写 `GLOSSARY.md`**：只记录"概念叫什么、是什么意思"
- **决策写本目录**：只记录"在多个方案中最终选了哪个、为什么"
